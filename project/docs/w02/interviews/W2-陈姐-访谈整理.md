访谈目的（页面填写）：了解门店怎样执行和记录总部的会员活动，门店和运营之间通常哪些信息需要核对，门店是否用过之前的智能营销平台，以及门店看到的老会员复购情况。用于判断助手可以进入哪个环节、会不会给门店增加工作。

## 一、陈姐说了什么（按话题，附原话位置）

### 1. 活动到店的执行流程

- 原话：活动到店后先核对三件事，"面向哪些会员、哪些门店参与、需要门店做什么"，再向门店同事说明，确认人员与执行安排；执行中收集顾客问题和门店反馈，"有不清楚的找运营核对"，结束后整理执行情况。（MSG-02603）
- 最近一次的具体情况、联系会员和发券的记录记在哪里、由谁记：不掌握。（MSG-02603）

### 2. 券的发放与核销

- 原话："券的发放和核销是两个环节，发放记录不能替代核销记录，具体状态和口径还要核实。"（MSG-02603，复述确认 MSG-02617）

### 3. 运营与门店之间要核对的事

- 举例：会员拿着线上活动来问门店能不能参加，门店先核对适用范围再说明，"不能只因为在线上看到了，就认定所有门店都能执行"。她说明这是常见场景，"不代表已经发生过某次具体事件"。（MSG-02603，MSG-02605 再次说明）
- 常要核对的五样：活动面向哪些会员、哪些门店参与、门店具体要做什么、现场顾客的问题该由谁答、门店付出的工作怎么记。"这些不清楚，门店就得一边接待一边来回找人问。"（MSG-02605）
- 原话："最费力的就是活动要求不清楚的时候"；希望适用范围、门店要做的事、问题由谁答能先讲明白。（MSG-02605）

### 4. 门店工作的记录与考核

- 原话：人员配合、现场接待、顾客问题反馈"得有个记录，不然门店出了力也体现不出来"。（MSG-02611）
- 原话："导购有会员注册指标，你们看会员相关的事，得把门店的考核放在一起看。线上怎么做，不能让门店这边的考核受到冲击。"（MSG-02611）

### 5. 系统与旧平台

- 门店用不用会员运营系统、旧平台门店有没有用过、用起来怎样：都不掌握，"不能替门店说成没用过"；系统情况找老周。（MSG-02607）

### 6. 复购与会员老化

- 原话："我能确认的是，会员复购率已经连续四个季度下滑，具体怎么算的，还得项目组核实。"（MSG-02609）
- 老会员回店的变化："手上没有能确认的观察依据，不能替门店下结论"。（MSG-02609）
- 会员老化："这是他的判断，我这边没有材料能证实，也补不出原因"。（MSG-02609）

### 7. 确认权与试点

- 原话："执行确认在门店人员，不是我代他们点头。"（MSG-02613，复述确认 MSG-02617）
- 她负责自己范围内门店的日常执行和人员配合；活动要求不清楚或影响门店考核的，会先要求澄清、调整，"不能默认门店已经接受"。（MSG-02613）
- 试点：在自己负责的门店范围内可以安排人员配合；前提是活动适用范围、具体工作量、现场问题谁处理、门店工作怎么记先说清楚，"门店人员确认了才算数"。（MSG-02613）
- 不能单独定：考核规则、跨部门预算和验收；预算和合同要王经理参与。（MSG-02613，MSG-02617）
- 考核规则由谁定：不掌握，"也不能替其他部门确认"。（MSG-02617）
